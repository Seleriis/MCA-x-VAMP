# MCA Reborn x Vampirism Compat 2.1.0

## MCA 7.7.36 support

- Updated for MCA Reborn `7.7.36-beta.3+1.21.1`.
- Reworked faction commerce and Cycle Trades around MCA's current native merchant transaction, preserving discounts, offer uses, XP and demand without copied offers.
- Migrated trait registration to MCA's ResourceLocation registry while keeping existing world data and legacy trait aliases intact.

## Installation

Replace the old compatibility JARs together. If Easy Villagers is installed, use `mca-ev-compat-1.21.1-2.1.0.jar`; its 2.0.0 version is not compatible with MCA 7.7.36.
