# MCA Reborn x Vampirism Compat 2.0.33

## Village Favor Invitations

- Village requests are now invitations. Choose **Accept** or **Decline** directly in the localized chat message.
- After accepting, the resident who asked is outlined only for you, making them easy to find without exposing the marker to other players.
- The resident's name is highlighted in favor messages and the dialogue now sounds more like a villager asking for help.
- **Crimson Reserve** now asks for three ordinary Vampirism Blood Bottles (`vampirism:blood_bottle`) rather than Vampire Blood Bottles.

## Compatibility

- Active requests from 2.0.32 remain accepted and can still be completed after updating.
- Declining, invalidating or completing a request preserves the existing cooldown and never changes villager faction, trade, AI or identity data.
