# MCA Reborn x Vampirism Compat 2.0.13

## Fixed

- Fixes faction-aware MCA trades that could desynchronize payment and output when Shift-clicking a stackable result.
- Live MCA villagers now use MCA's own merchant menu and offer transaction, with faction prices applied only while the trade screen is open.
- Easy Villagers Trader sessions now use and persist the same stored offer that processes the trade.
- Cycle Trades is still disabled immediately after the first completed trade.

## Compatibility

- No configuration keys or faction rules changed.
- Existing worlds, villagers, Easy Villagers stacks and Book of Occult Arts data remain compatible.
