# MCA Reborn x Vampirism Compat 2.1.1

Requires **Minecraft 1.21.1**, **NeoForge 21.1.x**, **Java 21** and
**MCA Reborn 7.7.36-beta.3+1.21.1**.

## Fixed trait names

- Restores the visible names and descriptions of the Vampire, Hunter and
  Werewolf traits in MCA's interaction UI.
- Keeps both the previous translation keys and MCA 7.7.36's new
  dot-separated ResourceLocation keys, so existing saved villagers need no
  conversion.

If Easy Villagers is installed, keep using
`mca-ev-compat-1.21.1-2.1.0.jar` alongside this release.
