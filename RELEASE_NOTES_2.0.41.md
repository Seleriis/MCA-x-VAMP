# MCA Reborn x Vampirism Compat 2.0.41

## Native Village Favor Conversation

Village favors now use MCA's own conversational rhythm. When you ask a resident **Could you use a hand?**, their request is spoken in MCA chat while the MCA screen presents only your reply.

Accepting, declining, checking on a favor or giving up now receives a short reply in chat and then closes the conversation. The resident's name is no longer repeated inside the compat's dialogue text, and the Book of Occult Arts explains the updated flow.

This update does not change favor requirements, deadlines, rewards, faction rules or saved mission data.
