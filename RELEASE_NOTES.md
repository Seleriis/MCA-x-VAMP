# MCA Reborn x Vampirism Compat — Release Notes

## Current release: 2.1.7

Requires **Minecraft 1.21.1**, **NeoForge 21.1.x**, **Java 21** and
**MCA Reborn 7.7.36-beta.3+1.21.1**. When Easy Villagers is installed, use
**mca-ev-compat 2.1.0** alongside this mod.

### Highlights

- MCA Vampires now receive Vampirism's native special-offer opportunity at
  MCA's actual offer-generation boundary, including the initial professional
  list, Cycle Trades and profession refreshes. The native one-in-three chance
  and heart, emerald and blood-bottle offer pool are preserved.
- Standard melee attacks from Vampire players, including Better Combat hits,
  no longer count as bites. Feeding, infection and Hunter toxic blood remain
  exclusive to Vampirism's native feeding flow.
- Hunter villagers can patrol against revealed Vampire players when enabled,
  while disguises and the configured defensive-only policy remain respected.
- The MCA 7.7.36 trade, trait and localisation updates preserve real merchant
  transactions, Cycle Trades, faction prices and player-facing trait names.
