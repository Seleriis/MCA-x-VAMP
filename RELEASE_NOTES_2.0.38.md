# MCA Reborn x Vampirism Compat 2.0.38

## Compact Village Mission UI

Village favors no longer fill the chat window with narration.

- A new request is a single compact chat line with **Accept** and **Decline** buttons.
- Acceptance, reminders, completion, cancellation and expiry use the temporary action bar instead of permanent chat lines.
- The clickable **Cancel request** action remains in chat immediately after accepting a favor.
- All three languages now use concise mission wording.

This is a presentation-only update. Mission rewards, quantities, deadlines, cooldowns, faction rules and saved mission data are unchanged.
