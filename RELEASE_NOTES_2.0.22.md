# MCA Reborn x Vampirism Compat 2.0.22

## Trader workstation refinement

Faction-specialist workstation clicks in an Easy Villagers Trader no longer predict a temporary insertion on the client.

When the stored MCA villager has an incompatible faction, the server now consumes only the interaction: the block stays in the player's inventory and is not placed in the world. Compatible villagers still receive their specialist profession normally.
