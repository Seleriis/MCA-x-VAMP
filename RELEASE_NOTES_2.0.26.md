# MCA Reborn x Vampirism Compat 2.0.26

## Fixes

- Vampire village fog now uses the same MCA village boundary on both the server and the client.
- Adding or removing MCA village buildings immediately expands or shrinks the visible fog.
- Totems outside an MCA village continue using Vampirism's normal fog area.

## Compatibility

Minecraft 1.21.1, NeoForge 21.1.234, MCA 7.7.25+1.21.1 and Vampirism 1.10.12.
